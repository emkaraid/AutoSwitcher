# AutoSwitcher

Тихая menu-bar утилита для macOS, которая автоматически исправляет текст, набранный в неправильной раскладке. Набираешь `ghbdtn` в английской раскладке вместо `привет` — приложение само удалит ошибочный текст, переключит раскладку и напечатает правильный вариант. Работает во всех текстовых полях системы.

Аналог [Caramba Switcher](https://caramba-switcher.com) / Punto Switcher. Без интернета, телеметрии и подписок — всё локально.

---

## Возможности

- **Автокоррекция EN ↔ RU** — системный перехват через `CGEventTap`, работает в любых приложениях (Notes, Safari, Telegram, Mail и т.д.).
- **Флаг раскладки в строке меню** — 🇺🇸 / 🇷🇺, обновляется мгновенно при каждом переключении (как в YouType).
- **Эвристика + словарь** — явные опечатки (`ghbdtn`, `ckj;yj`) ловятся эвристикой, остальное добивает `NSSpellChecker` (`руддщ` → `hello`).
- **Любая вариация раскладок** — таблица соответствий клавиш строится из реально включённых раскладок («Русская», «Русская – ПК», фонетическая; ABC, US, British), поэтому знаки препинания и ё конвертируются правильно в каждой.
- **Быстрый набор не ломает текст** — клавиши, нажатые во время исправления, придерживаются и допечатываются следом в правильной раскладке.
- **Smart Undo** — нажми `⌫` в течение 2 секунд после автокоррекции, и всё вернётся как было; слово попадёт во временный игнор на 30 секунд, а всплывающая подсказка предложит добавить его в словарь навсегда.
- **Отмена и конвертация по ⌥ Option** — короткий тап: откатить автокоррекцию, конвертировать текущее или последнее слово (повторный тап переключает обратно).
- **Конвертация выделенного текста по ⌥⇧R** — выделил кусок не в той раскладке → перепечатано (через буфер обмена, прежний текст буфера восстанавливается).
- **Исправление по Enter** — опционально (по умолчанию выключено).
- **Словарь исключений + самообучение** — слова, которые никогда не исправляются; после двух отмен одного слова оно добавляется автоматически.
- **Игнорирование терминалов и редакторов** — Terminal, iTerm2, VS Code, Xcode, JetBrains IDE, менеджеры паролей; список редактируется во вкладке «Приложения».
- **Пауза** — на 30 минут / 1 час / до перезапуска, прямо из меню.
- **Счётчик исправлений** — сегодня и всего, в меню.
- **Приватный журнал** — по умолчанию лог не содержит набранного текста; подробный режим включается вручную в настройках.
- **Проверка обновлений** — пункт меню, единственный сетевой запрос в приложении, только по клику.
- **Secure Input** — при защищённом вводе (пароли, sudo, экран блокировки) движок полностью останавливается.
- **Мастер разрешений** — при первом запуске приложение само показывает окно с кнопками, которые открывают нужные панели System Settings.
- **Два языка интерфейса** — русский и английский, переключается в настройках на лету.
- **Автозапуск при входе в систему** (`SMAppService`).

## Установка

### Из DMG (рекомендуется)

1. Скачай `AutoSwitcher-x.y.z.dmg` со [страницы релизов](https://github.com/emkaraid/AutoSwitcher/releases) (или собери сам: `./package.sh` → `dist/`).
2. Открой образ и перетащи **AutoSwitcher** на ярлык **Applications**.
3. Запусти приложение. Так как сборка не нотаризована Apple, при первом запуске сделай **правый клик → Open → Open** (либо сними карантин: `xattr -dr com.apple.quarantine /Applications/AutoSwitcher.app`).
4. Приложение покажет окно настройки разрешений — нажми кнопки **«Открыть настройки»** и включи AutoSwitcher в обоих списках:
   - Privacy & Security → **Accessibility** (Универсальный доступ)
   - Privacy & Security → **Input Monitoring** (Мониторинг ввода)
5. Как только Input Monitoring включён, AutoSwitcher **сам перезапустится** — готово.

Проверка: открой Notes и набери `ghbdtn ` (с пробелом) — должно превратиться в `привет `.

### Из исходников

Требования: macOS 13+, Xcode Command Line Tools.

```bash
git clone https://github.com/emkaraid/AutoSwitcher.git
cd AutoSwitcher
./install.sh        # соберёт и поставит в /Applications, сбросит старые TCC-записи
```

> ℹ️ macOS привязывает разрешения к подписи приложения. Сборки с ad-hoc подписью (по умолчанию на чужом Mac) получают новый отпечаток при каждой пересборке — разрешения приходится выдавать заново. Если в связке ключей есть сертификат «AutoSwitcher Local Dev» (`SIGN=stable ./build.sh` создаст его один раз), `build.sh` подписывает им, и разрешения переживают обновления. Релизы на GitHub начиная с 1.4.3 подписаны так.

## Использование

Иконка в строке меню показывает текущую раскладку (🇺🇸 / 🇷🇺). Клик открывает меню:

| Пункт | Что делает |
|---|---|
| **Включить AutoSwitcher** | Глобальный on/off движка (иконка меняется на клавиатуру). |
| **Сменить раскладку на …** | Ручное переключение EN ⇄ RU. |
| **Приостановить** | Пауза на 30 мин / 1 час / до перезапуска (иконка ⏸). |
| **Исправлено сегодня / всего** | Счётчик полезных автокоррекций. |
| **Настроить разрешения…** | Окно-мастер выдачи разрешений (виден, только если чего-то не хватает). |
| **Настройки…** | Окно настроек: Основные + Словарь + Приложения. |
| **Проверить обновления…** | Сравнивает версию с последним GitHub-релизом и открывает страницу загрузки. |
| **Перезапустить / Завершить** | Управление процессом. |

Журнал диагностики (`~/Library/Logs/AutoSwitcher/debug.log`) открывается из Настройки → Основные → Диагностика.

### Настройки → Основные

- Язык интерфейса (системный / русский / английский)
- Запуск при входе в систему
- Умная отмена по Backspace, отмена/конвертация по ⌥, конвертация выделенного по ⌥⇧R
- Исправление по Enter (по умолчанию выключено)
- Предложение и автодобавление слов в словарь (после двух отмен)
- Звук при автопереключении
- Игнорирование слов с цифрами и символами
- Статус разрешений с кнопками перехода в System Settings
- Диагностика: подробный журнал (по умолчанию без набранного текста) + кнопка «Открыть журнал»

### Настройки → Словарь

Слова-исключения, которые никогда не исправляются: `ssh`, `git`, `npm`, никнеймы, аббревиатуры. Сравнение регистронезависимое.

### Настройки → Приложения

Приложения, в которых движок не работает. Добавление через выбор `.app`, удаление, возврат стандартного списка.

## Сборка и упаковка

```bash
./build.sh                # release build → ./AutoSwitcher.app
./build.sh debug          # debug build
CLEAN=1 ./build.sh        # пересборка с нуля
./package.sh              # сборка + DMG → dist/AutoSwitcher-<версия>.dmg
./install.sh --force      # переустановка в /Applications
./scripts/test.sh         # тесты детектора (--quiet — только итог)
./scripts/e2e.sh          # сквозной тест установленного приложения (~1 мин, печатает сам)
```

`scripts/e2e.sh` открывает своё тестовое окно и печатает в него настоящими нажатиями клавиш: проверяет исправления, быстрый набор, ⌥, ⌥⇧R и сохранность буфера обмена. Перед каждым нажатием он убеждается, что активно именно его окно, — иначе останавливается. Нужны запущенный AutoSwitcher и право на «Универсальный доступ» у процесса, из которого запускается скрипт.

Тесты — обычный Swift-исполняемый файл (`scripts/tests/main.swift`), который компилируется вместе с исходниками детектора и прогоняет его через настоящие словари `NSSpellChecker` и включённые на Mac раскладки. Ожидания по пунктуации написаны под маковскую «Русскую».

Сборка и подпись выполняются во временной папке вне проекта — это важно, если проект лежит в iCloud-синхронизируемой папке (Desktop/Documents), где file provider вешает на файлы xattr'ы, ломающие codesign.

## Архитектура

```
AutoSwitcherApp                          @main SwiftUI App, MenuBarExtra с флагом
 ├─ AppDelegate                          lifecycle, singletons, onboarding
 │   ├─ PermissionsManager               AX + Input Monitoring + Secure Input
 │   ├─ LayoutManager                    Carbon TIS (current/switchTo, main-thread)
 │   ├─ LayoutState                      наблюдатель смены раскладки → флаг
 │   ├─ AutoCorrector                    backspace → switch → retype (bg queue)
 │   └─ KeyboardMonitor                  CGEventTap на main runloop, буфер, детект
 │       ├─ LayoutDetector               EN↔RU позиционная таблица + эвристики
 │       │   └─ WordChecker              NSSpellChecker
 │       ├─ SmartUndoManager             окно отката 2 секунды
 │       └─ AppIgnoreList                кэш frontmost bundle id (без XPC на каждый кейстрок)
 ├─ Views                                меню, настройки, словарь, тост, onboarding
 └─ Models                               AppSettings (UserDefaults), L10n (EN/RU)
```

Ключевые решения:

- **Tap на главном runloop** — на macOS 14+ приватные dispatch-queue runloop'ы теряют доставку событий при миграции worker-потоков GCD.
- **Горячие клавиши (⌘/⌃/⌥) очищают буфер** — шорткаты не являются текстовым вводом и не должны попадать в детектор.
- **Раскладка выводится из скрипта букв буфера**, а не только из системы — защита от гонки, когда система ещё не применила переключение, а пользователь уже печатает.
- **Синтезированные события помечаются** `eventSourceUserData = 0xA17C0DE`, чтобы tap их игнорировал.
- **`TISSelectInputSource` только на главном потоке** (требование Apple), вызовы с фоновой очереди маршалятся через `DispatchQueue.main.sync`.

## Диагностика

Лог пишется в `~/Library/Logs/AutoSwitcher/debug.log` (пересоздаётся при каждом запуске) и дублируется в unified log:

```bash
tail -f ~/Library/Logs/AutoSwitcher/debug.log
# или
log stream --process AutoSwitcher
```

Нормальный запуск выглядит так:

```
=== AutoSwitcher launched ===
PermissionsManager init — AX=true  InputMonitoring=true
CGEventTap installed successfully
tap attached to main runloop and enabled
first keyDown delivered to tap — engine is live
```

### Частые проблемы

- **Разрешения стоят, но не работает** — в TCC-базе осталась запись от старой сборки. Сброс: `tccutil reset Accessibility com.autoswitcher.app && tccutil reset ListenEvent com.autoswitcher.app`, затем выдать заново.
- **Слово не исправляется** — оно в словаре исключений, активное приложение в игнор-листе, включён Caps Lock, или в слове есть цифры/символы при включённой соответствующей опции.
- **Gatekeeper не даёт запустить** — правый клик → Open, или `xattr -dr com.apple.quarantine /Applications/AutoSwitcher.app`.

## Известные ограничения

- Только пара **EN ↔ RU** (расширение = новые позиционные таблицы в `LayoutDetector`).
- Без Apple Developer ID ($99/год) разрешения слетают при каждой пересборке и нет нотаризации.
- Приложения с собственным низкоуровневым вводом (некоторые Electron-редакторы) могут игнорировать синтезированные события.
